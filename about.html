ABOUT

关于这个小站

一个纯静态的个人小站：没有后端、没有数据库、没有跟踪脚本，所有功能都在你的浏览器里跑。

它是什么

几个部分：口袋工具箱（59 个常用小工具）、游戏中心（16 款本站游戏 + 12 个原作者外链 + 中国象棋），还有一份 在线资源 清单（201 个入口：小说、音乐、影视、漫画、云游戏、游戏平台）。

做它的理由很简单——平时总会遇到「要转个 Base64」「要算个时间戳」「想摸鱼玩两把」「找本站哪儿看剧」这种小事，开一堆网站不如自己攒一个。

普通工具都在你的浏览器里算：输入的内容不上传，刷新就没了。有两个例外，页面上都写明了——API Key 检测会把 key 发到中转服务再转给对应厂商（中转只转发、不留存）；外链点开会到别人的站。

以前在关于页挂过一个访问计数器（不蒜子），已经删掉了。现在整站没有任何统计脚本。

用了什么

  • 原生 HTML / CSS / JavaScript，零第三方依赖
  • 托管在 GitHub Pages，PWA 离线可用
  • 没有框架、没有构建步骤，改一行就生效

说明与免责

该说清楚的先说清楚
