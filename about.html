ABOUT

关于这个小站

一个纯静态的个人小站：没有后端、没有数据库、没有跟踪脚本，所有功能都在你的浏览器里跑。

它是什么

两件事：口袋工具箱（25 个常用小工具）和 游戏（7 个经典复刻）。

做它的理由很简单——平时总会遇到「要转个 Base64」「要算个时间戳」「想摸鱼玩两把」这种小事，开一堆网站不如自己攒一个。

所有工具都是本地计算：你输入的内容不会上传到任何服务器，刷新就没了。

用了什么

  • 原生 HTML / CSS / JavaScript，零第三方依赖
  • 托管在 GitHub Pages，PWA 离线可用
  • 没有框架、没有构建步骤，改一行就生效
