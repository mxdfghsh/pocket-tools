WEB GAMES

网上搬来的经典

都是成熟的开源作品（做过很多年的那种），不是我自己写的。手机直接玩。

🎁 抓娃娃机

圣诞主题的抓娃娃机：倒计时内抓满奖励，和商场里那种一样。

开始 → ⛏️ 黄金矿工

4399《黄金矿工》的 HTML5 复刻：钩子来回摆，抓金块、抓石头、买道具，关卡跟原版对齐。

开始 → 🎣 钓鱼生活

离线摸鱼小游戏，钓上来什么全看运气。适合发呆的时候玩。

开始 → 🐟 捕鱼达人

转炮台打鱼，越大的鱼越值钱。手机上点屏幕转炮口。

开始 → 🍄 超级马里奥（无限版）

Infinite Mario 网页版：跑跳、踩蘑菇、顶砖块，关卡无限生成。开源（Unlicense），不是任天堂原版但玩法一样。

开始 → 🔦 3D 迷宫（Astray）

第一人称 3D 迷宫，拿手电筒找出口。想要 3D 感的话，这个最接近。

开始 → 🌍 Luanti（开源版我的世界） 手机可玩

免费开源的方块沙盒，玩法接近我的世界，安卓手机装 App 就能玩，触屏操作。不是网页，但确实是手机上最接近的选择。

去官网下载 ↗ ⛏️ 我的世界 · 官方网页版

⚠️ 只在电脑上能玩：官方检测到手机没有键盘会直接拒绝加载。有电脑的话可以点开。

需要电脑键盘 🔢 2048

原版开源 2048，滑动合并数字，全世界都在玩的那个。

开始 → 🐦 像素小鸟

Clumsy Bird，点一下飞一下，别看简单，很容易上瘾。

开始 → 🔷 六边形消除

Hextris，转六边形把同色块凑到一起消掉，节奏一快就上头。

开始 → 👻 吃豆人

Pac-Man 网页版，吃掉所有豆子别被鬼抓到。
