# fishgame

A fishing arcade game built with **vanilla JavaScript** and **HTML5 Canvas** — no frameworks, no libraries, just pure native web technology.

[live demo](https://BlueYu-0221.github.io/fishgame/)

## How to run

Simply open `index.html` in your browser — no build tools or server required.

## How to play

Move your mouse across the canvas to aim the cannon, then click to fire at the fish and score points.
