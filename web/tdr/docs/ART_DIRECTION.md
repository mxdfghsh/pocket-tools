# 荒原哨站 · 美术方向

## 视觉目标

保留原有的竖屏自动塔防和随机卡牌玩法，将几何图形演示升级为具有完整世界观的「荒原工业哨站」。低饱和苔绿地表、石灰金属与沙金色指令构成统一的环境、单位和界面语言。

## 参考与边界

- [The Tower — Idle Tower Defense](https://www.techtreegames.com/thetower)：借鉴单塔自动防御的易读战场、射程提示与低干扰反馈。
- [Dome Keeper](https://store.steampowered.com/app/1637320/Dome_Keeper/)：参考工业防御与荒野环境的氛围、克制的色彩层次；不照搬像素风或其地形。
- 场景、炮塔、虫群和图标全部使用项目内原创 Canvas / SVG 绘制，不复制上述游戏的角色、UI、截图或商业素材。
- 无图片生成 API、远程字体或第三方资源依赖；页面直接打开也能运行。

## 配色与层级

| 用途 | 色值 | 原则 |
| --- | --- | --- |
| 页面底色 | `#101919` | 低干扰，保留环境深度 |
| 主要文字 | `#e7eee5` | 关键标题与数据的明度最高 |
| 次级文字 | `#879c96` | 与主要信息拉开层级 |
| 部署 / 强化 | `#e5b777` | 沙金色，只突出关键动作 |
| 装甲 / 在线 | `#a0d9b8` | 柔和薄荷绿，表示正常状态 |
| 危险 / 失守 | `#eb8d7c` | 珊瑚红，不与常规状态混用 |

稀有度：普通灰绿、稀有青色、史诗淡紫、传说沙金。每张卡同时显示稀有度文字，避免仅用颜色传达信息。

元素：火为暖橙、冰为冷青、雷为淡金、毒为黄绿。炮塔指示灯、弹道、命中效果与 HUD 弹药标签保持一致。

## 场景与单位

- 固定种子的地表纹理、六边形路面、岩石、荒草、货箱、障碍物、电缆与编号标识建立哨站语境。
- 地形一次绘制到离屏画布，后续帧仅合成；环境浮尘与警戒扫描保持低频率、低亮度。
- 哨塔拥有六边形底座、固定支架、旋转炮身、装甲面、散热槽、炮口与元素灯；多重射击会增加副炮外观。
- 普通敌人为圆背游荡者，快速敌人为尖甲疾行兽，坦克为分层重甲虫，首领为带尖刺的荒原领主。轮廓和运动差异在小尺寸下依然可识别。
- 受击火花、扩散冲击环、死亡碎片、元素轨迹和深色描边伤害文字构成战斗反馈，避免大面积泛光淹没敌人。

## 界面与交互

- 菜单、升级、暂停、结算和操作手册均使用 DOM；标题与描述不再依赖 Canvas 字体测量。
- 战斗时只保留顶部波次 / 装甲 / 经验和底部弹药 / 击杀 / 时间；桌面两侧为战术说明与炮塔参数。
- 卡牌在宽屏战场内三列展示，在战场宽度小于 400px 时改为竖排；不使用出界放大和持续晃动。
- 控件支持触摸、键盘、可见焦点与弹窗 Tab 焦点循环。帮助窗口暂停战斗，关闭后恢复之前的暂停状态。
- 尊重 `prefers-reduced-motion`：关闭装饰性移动、界面过渡及屏幕震动；战斗本身保持可玩。
- 切到后台自动暂停，防止玩家在看不到战场时失守。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `index.html` | 页面结构、原有战斗与卡牌逻辑、主循环 |
| `art.js` | 地表缓存、单位与特效绘制、原创图标与主题色 |
| `ui.js` | HUD 同步、卡牌与模块展示、操作与弹窗状态 |
| `styles.css` | 主题变量、桌面布局、战场容器适配、动画与焦点样式 |

渲染采用设备像素比，上限为 2，逻辑坐标维持 `480 × 720`，不改变原有射程与碰撞数值。常规 HUD 每 100ms 同步一次，且仅更新变化的文本和样式；界面切换立即同步。
