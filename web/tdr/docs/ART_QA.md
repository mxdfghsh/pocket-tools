## 布局

检查了 `320×568`、`375×667`、`390×844`、`768×1024`、`1366×768` 和 `844×390`。

- 无横向页面溢出。
- 卡牌全部位于战场内部，卡牌文字和底部提示不重叠。
- 全部 28 张卡牌在桌面和 320px 窄屏分别检查，无文字溢出、无缺失图标。
- 横屏短视口保留 420px 战场宽度，允许纵向滚动，不将游戏压缩成无法辨认的窄条。
- 触屏暂停按钮点击区域至少 40px，主要行动按钮至少 44px。

桌面主菜单、自然战斗、升级和结算，以及手机主菜单和升级的截图保存在 `docs/previews/`。升级预览固定了三张代表性卡牌，以覆盖长描述与不同稀有度；不影响正式卡牌随机逻辑。

## 渲染检查

对 80 个敌人、150 发带拖尾子弹、400 个粒子同时渲染的压力场景，连续调用了 40 次绘制。本次本机测量的绘制提交平均约 5.4ms，P95 约 10.7ms。

该数字仅代表本机无头 Edge 的 JavaScript 绘制调用耗时，不包括完整游戏物理、GPU 合成或真实设备显示延迟，不作为所有设备 60FPS 的保证。

验收期间未捕获到 JavaScript 页面运行错误。未验证 Firefox / Safari 真机、实际手机 GPU 或旧浏览器兼容性。
